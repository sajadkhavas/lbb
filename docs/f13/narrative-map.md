# Homepage Narrative Map

## 1. Identity

### سوال کاربر

این برند چیست و دقیقاً چه چیزی می‌فروشد؟

### پاسخ UI

- LBB / Tehran / Drop 001
- H1 فارسی کوتاه
- نام پنج خانواده محصول
- تعداد قطعه و دسته
- CTA اصلی فروشگاه
- CTA ثانویه هودی
- Hero product با قیمت و PDP مستقیم

## 2. Transparency

### سوال کاربر

آیا سفارش، ارسال و پرداخت واقعی فعال است؟

### پاسخ UI

Trust Strip بلافاصله بعد از Hero قرار دارد و وضعیت نسخه نمایشی، Local storage و پرداخت غیرفعال را بدون متن تبلیغاتی اعلام می‌کند.

## 3. Category Discovery

### سوال کاربر

از کدام نوع محصول شروع کنم؟

### پاسخ UI

پنج Category card با:

- نام فارسی
- Latin identifier
- Tagline
- تعداد محصول
- تصویر
- URL مستقل

## 4. Product Moments

### سوال کاربر

کدام قطعه‌ها برای شروع مهم‌ترند؟

### پاسخ UI

چهار محصول براساس `rank` کاتالوگ نمایش داده می‌شوند. عبارت Bestseller یا فروش ساختگی استفاده نمی‌شود.

## 5. Drop Story

### سوال کاربر

این قطعه‌ها چطور کنار هم قرار می‌گیرند؟

### پاسخ UI

Collection شبگرد، Story points و سه Product link را در یک Section متصل نمایش می‌دهد. Drop 02 فقط با وضعیت «در حال توسعه و بدون تاریخ تاییدشده» ذکر می‌شود.

## 6. Shop the Look

### سوال کاربر

داخل تصویر چه چیزهایی پوشیده شده؟

### پاسخ UI

Hotspotها مکمل‌اند؛ Product index شامل نام، SKU، قیمت و PDP همیشه دیده می‌شود و به Hover یا Click وابسته نیست.

## 7. Decision Support

### سوال کاربر

قبل از انتخاب نهایی چه اطلاعاتی لازم دارم؟

### پاسخ UI

- Fit و Size guide
- Shipping و Returns
- Material و Care
- Product truth checklist

## 8. Editorial Context

### سوال کاربر

فرم و ترکیب محصول را کجا بهتر بفهمم؟

### پاسخ UI

سه مسیر مستقل:

- Collection
- Lookbook
- Journal fit guide

## 9. Conversion Close

Brand Statement پیام را جمع‌بندی می‌کند و کاربر را به Shop یا About هدایت می‌کند. CTA خرید در پایان Narrative تکرار می‌شود، اما با پیام و Context متفاوت از Hero.

## 10. Community

Official Updates و Instagram فقط به کانال رسمی Link می‌شوند. Newsletter، Email collection یا موفقیت ساختگی بدون Backend نمایش داده نمی‌شود.

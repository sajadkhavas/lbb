
# LBB — نقشه تکمیل کامل فرانت (Full Modern Shop)

## وضعیت فعلی (بررسی‌شده)
- ۱۴ روت موجود: `/`، `/shop`، `/$category`، `/product/$slug`، `/cart`، `/checkout`، `/order-confirmation`، `/search`، `/wishlist`، `/about`، `/contact`، `/faq`، `/size-guide`، `sitemap.xml`
- **هیچ تصویر واقعی محصولی وجود ندارد** — `ProductCard` و همه صفحات از placeholder گرادیانی با متن «LBB» استفاده می‌کنند. این بزرگ‌ترین شکاف بصری فعلی است.
- کارت محصول کل خودش لینک است، پس دکمهٔ «افزودن به سبد» روی هاور واقعاً کار نمی‌کند (دکمه داخل `<Link>`).
- شبکهٔ shop فیلتر/مرتب‌سازی/صفحه‌بندی ندارد؛ فقط تب دسته‌بندی است.
- سبد فقط localStorage است؛ هیچ drawer/مینی‌کارتی نیست — هر افزودن یعنی رفتن به صفحهٔ سبد.
- `sonner` و کل کتابخانهٔ shadcn نصب هستند ولی تقریباً استفاده نمی‌شوند (بدون toast، بدون sheet، بدون skeleton).
- تب‌های دسته‌بندی در shop با `<a href>` هستند نه `<Link>` → هر کلیک full reload و از دست رفتن حس SPA.

## فاز ۱ — پایهٔ بصری: تصاویر واقعی و کارت محصول (بیشترین تأثیر)
- تولید ست تصاویر محصول (۴ زاویه برای هر محصول کلیدی) + تصاویر lifestyle دسته‌بندی‌ها + کاور هیرو، همه به‌صورت asset بومی پروژه.
- افزودن `images: string[]` به مدل `Product` و اتصال آن به کارت، گالری محصول، هیرو، Category Takeover و Featured.
- بازنویسی `ProductCard`: تصویر با hover swap (تصویر دوم)، `aspect-[3/4]`، `loading="lazy"` + `decoding="async"`، اسکلت blur تا لود شدن.
- رفع باگ ساختاری: دکمهٔ «افزودن سریع» از داخل `<Link>` بیرون می‌آید (لینک overlay + دکمهٔ مستقل روی آن) تا کلیک واقعی کار کند.

## فاز ۲ — تجربهٔ خرید (Commerce UX)
- **Cart Drawer**: کشوی راست‌چین با انیمیشن، شمارندهٔ زنده در نوبار و بار موبایل، دکمهٔ افزایش/کاهش، «رفتن به پرداخت».
- **Toast**ها با `sonner` برای افزودن به سبد / علاقه‌مندی / کپی کد تخفیف / خطای فرم.
- **Wishlist سراسری**: تبدیل به context مثل cart، آیکن قلب روی همهٔ کارت‌ها با وضعیت فعال.
- **Quick View**: مودال پیش‌نمایش محصول از داخل شبکه (انتخاب رنگ/سایز و افزودن بدون ترک صفحه).
- **پرداخت**: نوار پیشرفت مرحله‌ای، اعتبارسنجی با react-hook-form + zod، کد تخفیف، خلاصهٔ سفارش چسبان.

## فاز ۳ — فروشگاه و کشف محصول
- **فیلتر واقعی** در `/shop` و `/$category`: دسته، رنگ، سایز، بازهٔ قیمت، فقط موجودها، تخفیف‌دارها.
- **مرتب‌سازی**: جدیدترین، ارزان‌ترین، گران‌ترین، محبوب‌ترین.
- همگام‌سازی فیلترها با **search params** روت (قابل اشتراک‌گذاری + SSR-friendly)، با `canonical` روی نسخهٔ بدون پارامتر.
- شیت فیلتر موبایل + چیپ‌های فیلتر فعال قابل حذف.
- صفحه‌بندی یا «نمایش بیشتر» + حالت خالی طراحی‌شده.
- ارتقای جست‌وجو: پیشنهاد زنده در نوبار، جست‌وجوهای اخیر، هایلایت عبارت.

## فاز ۴ — صفحهٔ محصول در سطح برند
- گالری تصاویر با thumbnail عمودی، zoom روی هاور دسکتاپ و swipe موبایل.
- نوار خرید چسبان موبایل (قیمت + افزودن به سبد).
- تب‌های توضیحات / جنس و مراقبت / ارسال و مرجوعی.
- بخش نظرات (داده‌های نمونه) + امتیاز ستاره‌ای، متصل به `AggregateRating` در JSON-LD.
- «شاید بپسندید» و «اخیراً دیده‌شده» (localStorage).
- راهنمای سایز به‌صورت مودال داخل صفحه.

## فاز ۵ — صفحات جدید موردنیاز
- `/lookbook` — گالری ادیتوریال (مسنری + لایت‌باکس)، بسیار مؤثر برای برند استریت‌ویر.
- `/collections/$slug` — کالکشن‌های فصلی/کپسولی (Drop) جدا از دسته‌بندی.
- `/track-order` — پیگیری سفارش با کد رهگیری.
- `/shipping-returns` — ارسال و مرجوعی (صفحهٔ اعتماد و SEO).
- `/terms` و `/privacy` — الزامی برای فروشگاه واقعی.
- `/journal` (وبلاگ سبک) — موتور اصلی SEO محتوایی: فهرست + `/journal/$slug`.
- `/stores` یا بخش تماس حضوری در صورت داشتن فروشگاه فیزیکی.
- همه با `head()` اختصاصی و JSON-LD مناسب.

## فاز ۶ — صفحهٔ اصلی: زیباتر و پرامکانات‌تر
صفحهٔ فعلی ساختار خوبی دارد ولی هنوز جای رشد دارد:
- هیرو با تصویر واقعی + reveal ماسک‌دار و CTA دوگانه (خرید مردانه / زنانه یا کالکشن جدید).
- **New Drop / Countdown** — شمارش معکوس عرضهٔ بعدی.
- **Shop the Look** — ست کامل با نقاط قابل کلیک روی تصویر.
- **Editorial Split** — روایت برند با تصویر + متن متناوب (zigzag).
- **نظرات مشتریان** — کاروسل تستیمونیال با عکس واقعی خرید.
- **Newsletter** با طراحی full-bleed قرمز و اعتبارسنجی.
- **بنر تخفیف/ارسال رایگان** بالای نوبار (قابل بستن).
- **اینستاگرام** با تصاویر واقعی به‌جای placeholder.
- ریزتعامل‌ها: magnetic buttons، هاور تصویری روی منوی دسته‌ها، ترنزیشن نرم بین صفحات.

## فاز ۷ — سرعت، پایداری و کیفیت فنی
- **تصاویر**: افزودن `vite-imagetools`، خروجی AVIF/WebP، `srcset` واکنش‌گرا، `preload` فقط برای تصویر LCP هیرو، `fetchpriority="high"`.
- **JS**: GSAP/ScrollTrigger فقط dynamic import و فقط وقتی سکشن نزدیک viewport است؛ Lenis غیرفعال روی `prefers-reduced-motion` و موبایل ضعیف.
- **رندر**: تبدیل همهٔ `<a href>`های داخلی به `<Link>` (الان تب‌های دسته‌بندی reload کامل می‌کنند) + `preload="intent"` برای ناوبری آنی.
- **فونت**: `display=swap` (موجود) + `preload` فایل woff2 اصلی Vazirmatn و کاهش وزن‌های بارگذاری‌شده.
- **CSS**: خروج از استایل‌های inline تکراری `fontFamily` و انتقال به توکن‌های `styles.css`.
- **پایداری**: بدون CLS — نسبت ابعاد ثابت روی همهٔ تصاویر و اسکلت‌ها.
- **دسترس‌پذیری**: focus ring، aria-label فارسی، قابلیت کار با کیبورد در drawer/مودال، کنتراست AA.
- **SEO**: بررسی نهایی canonical/robots همهٔ روت‌ها، sitemap شامل صفحات جدید، breadcrumb JSON-LD در همهٔ صفحات عمقی.
- بازبینی نهایی با اجرای واقعی مرورگر و اسکرین‌شات هر صفحه در دسکتاپ و موبایل.

## جزئیات فنی
- بدون بک‌اند: همه چیز فرانت + localStorage. اگر بعداً سفارش واقعی، ورود کاربر یا پنل ادمین خواستید، به Lovable Cloud نیاز است (فاز جدا).
- فیلترها با `validateSearch` + `zod` روی روت پیاده می‌شوند تا SSR سالم بماند.
- Drawer/مودال از رادیکس موجود (`dialog`, `sheet` از vaul) استفاده می‌کنند — نصب اضافه لازم نیست.
- تنها پکیج جدید احتمالی: `vite-imagetools` برای فرمت‌های تصویری.
- ترتیب اجرا: ۱ → ۲ → ۳ → ۴ → ۶ → ۵ → ۷ (تصاویر و کامرس اول، صفحات محتوایی بعد، بهینه‌سازی آخر).
